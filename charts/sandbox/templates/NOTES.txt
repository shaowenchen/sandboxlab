Create a sandbox with the CLI from
https://github.com/shaowenchen/sandboxlab:

  export SANDBOX_URL='{{ if .Values.publicURL }}{{ .Values.publicURL }}{{ .Values.basePath }}{{ else }}http://localhost:8080{{ .Values.basePath }}{{ end }}'
  export SANDBOX_KEY="$({{ $readBack }})"

  sandbox catalog
  sandbox create -t agent-infra --name myshop
  sandbox url myshop

The catalog is compiled into the control plane; read it with `sandbox catalog`
or `GET /api/v1/catalog`. Add one to the running deployment with `sandbox
catalog add <file>` — it is held in memory and not persisted.

Sandboxes live in namespaces of their own, named {{ .Values.sandboxNamespacePrefix }}<id>,
and are deleted when their lifetime runs out. Uninstalling this release removes
the ones that are still running.
